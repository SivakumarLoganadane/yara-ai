# YARA AI – Download for Windows

**YARA AI (Your Autonomous Reasoning Assistant)** is a personal AI assistant that runs on your own Windows computer: local chat, conversational memory, answers from your documents, text/code/document generation, image generation and image editing. After a one-time model setup it works offline.

**[Download YARA_AI_Setup.exe](https://github.com/SivakumarLoganadane/yara-ai/releases/latest/download/YARA_AI_Setup.exe)** · [Website](https://sivakumarloganadane.github.io/yara-ai/) · [All releases](https://github.com/SivakumarLoganadane/yara-ai/releases)

- Windows 10 or 11, 64-bit · 8 GB RAM (16 GB recommended) · no GPU needed
- About 3 GB for the program plus about 7 GB of AI models, installed once by the built-in Model Setup (download, or import from a folder for offline PCs)
- Your data stays on your computer in `%LOCALAPPDATA%\YARA AI`

This repository hosts the download page and the installer releases only. The YARA AI source code is not published here.
